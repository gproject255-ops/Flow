# Flow

Mobile-first session planner for long, focused sessions.

Minimal dark design. Local progress tracking. Different intensity modes.

## Features

- Multiple session modes (Chill → Deep → Full)
- Timed stages with rotating tips
- Local history & basic stats
- Subscription tiers (UI ready)
- Fully mobile-optimized

## How to run

Just open `index.html` in any modern browser (Chrome / Safari recommended).

No build step required.

## Tech

- Vanilla HTML / CSS / JavaScript
- localStorage for persistence
- No backend yet

## Status

Early prototype. Work in progress.
